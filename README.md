# anomartsy.xyz

The main website for **AO (Anom Originals)**.
Live at **[anomartsy.xyz](https://anomartsy.xyz)**.

The front door to everything AO: the art, the shop, kids' stories,
games, and the lore.

## Pages

- `index.html` — homepage
- `gallery.html` — art gallery
- `custom.html` — commission info
- `kids-corner.html` — Anom's Corner stories (Pixel & Dot, Tater & Clifford)

- `stories.html` — story index
- `ao-cosmology.html` — the AO Universe lore
- `about.html`, `contact.html`
